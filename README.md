# Blueprint to C++ Conversion Assignment

This assignment focuses on converting existing Unreal Engine Blueprints and Structs into C++ classes and headers. The main goals are:

- Fork the original repository, create a new branch named `assignment`, and clone it locally.
- Integrate provided content files into the project structure.
- Open the project in Unreal Engine, add StarterContent, and set up the environment.
- Convert all Blueprint classes and structs (14 classes + 1 struct) into C++ `.h` and `.cpp` files following the original hierarchy.
- Implement only declarations and empty function bodies (returning default values where necessary).
- Maintain exact parameter and variable types.
- Use consistent naming conventions (CamelCase) and apply the Category `"BirdOfPrey"` to properties and functions.
- Avoid converting any Blueprint logic or ConstructionScripts—focus solely on class structure and interfaces.

This exercise strengthens understanding of Unreal Engine C++ workflows, Git branching, and project structure management.
